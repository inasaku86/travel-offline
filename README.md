# Travel-Offline

SNS/ブラウザなどの誘惑アプリをブロックしている間の「連続オフライン時間」と「移動軌跡」を記録し、旅の実績として可視化・シェアできるモバイルアプリ。

## 背景

バックパッカー旅行中、インターネットでほとんどの問題が解決する状況が「イージーモード」に感じられた。旅行中に使用できるアプリを制限してある種のチャレンジとして旅を楽しめたら楽しいのではというのが出発点。
「運動して時間を稼ぎ、SNSを解禁する」というコンセプトのアプリは存在するが、本アプリは逆に **ブロックする間の体験を楽しむ** というコンセプト。

## コンセプト

- チャレンジを開始すると、指定したアプリ（SNS・ブラウザ・マップ等）がブロックされる
- ブロック中の経過時間を計測し、日次で連続記録として蓄積
- 同時にGPSで移動軌跡を記録し、地図上にルートとして描画
- チャレンジ終了時に「◯時間◯分オフライン／◯km移動」をまとめたシェア画像を生成

## 主な機能（予定）

- [ ] チャレンジ開始/終了（指定アプリの起動ブロック）
- [ ] 連続オフライン時間の計測・ストリーク表示
- [ ] GPS移動軌跡の記録・地図描画
- [ ] シェア用画像の自動生成

## 技術スタック

まずiOS版から着手し、反応を見てAndroid版を追う方針。

### iOS（先行）
- 言語: Swift / SwiftUI
- アプリブロック: Screen Time API（FamilyControls / ManagedSettings / DeviceActivity）
- 位置情報: Core Location（バックグラウンド取得）
- 配布（検証フェーズ）: TestFlight

### Android（後続予定）
- 言語: Kotlin
- アプリブロック: AccessibilityService + オーバーレイ
- 位置情報: FusedLocationProviderClient

### バックエンド
- MVP: Firebase（Auth / Firestore / Storage）
- 地図描画: Mapbox（またはMapLibre）
